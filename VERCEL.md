# Vercel deployment

This project is designed for Vercel.

1. Push the extracted folder to GitHub.
2. Import the repository in Vercel.
3. Framework preset: Next.js.
4. Build command: `next build` (or leave Vercel default).
5. Install command: `npm install`.
6. No environment variables are required for the starter.
7. Deploy.

For a production portfolio, replace the placeholder GitHub/Kaggle/Resume URLs and add optimized assets under `public/`.

The Three.js scene is client-only and loaded dynamically, so it is compatible with Next.js server rendering and Vercel deployment.
